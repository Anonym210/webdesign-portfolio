# Bildnachweise & Lizenzen

Alle verwendeten Fotos stammen von **[Unsplash](https://unsplash.com)** und stehen unter der
[Unsplash-Lizenz](https://unsplash.com/de/lizenz).

## Was die Unsplash-Lizenz erlaubt

| | |
|---|---|
| ✅ Kostenlose Nutzung | privat **und kommerziell** |
| ✅ Kundenprojekte | Verwendung auf Websites, die Sie für Kunden bauen, ist erlaubt |
| ✅ Bearbeitung | Zuschneiden, Farbanpassung, Überlagerungen |
| ✅ Keine Namensnennung nötig | Attribution ist erwünscht, aber **nicht Pflicht** |
| ❌ Weiterverkauf der Bilder | Bilder dürfen nicht als eigene Stock-Fotos verkauft werden |
| ❌ Konkurrenzdienst | Kein Aufbau eines konkurrierenden Bilddienstes |

> **Wichtig für Kundenprojekte:** Die Lizenz erlaubt die Nutzung in Kundenwebsites.
> Sie darf aber nicht so wirken, als seien die abgebildeten Personen oder Orte
> tatsächlich der Kunde. Deshalb wurden hier bewusst Motive **ohne erkennbare
> Gesichter** gewählt — sobald echte Fotos der Praxis vorliegen, sollten diese
> die Stock-Bilder ersetzen.
